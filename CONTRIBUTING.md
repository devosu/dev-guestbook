# Contributing

Thanks for joining in! Please follow these 3 rules:

1. **One file per person.** Add exactly one new file to the `attendees/` folder.
2. **Only edit your own file.** Do not change anyone else's file, the template, or anything outside `attendees/`.
3. **Name it after your GitHub username.** For example, if your username is `octocat`, your file is `attendees/octocat.md`.

A robot checks every pull request for these rules. If it finds a problem, it will tell you what to fix.
